Setup for admins (run once on office Mac)
  1. Clone this repo and add router passwords to wifi-region-scanner/routers.json (never commit passwords).
  2. In Terminal.app: cd wifi-region-scanner && npm install && npm run ui
  3. Click Detect live regions above (with scanner server set to that Mac’s IP).
  4. Commit docs/routers-directory.json (router list, no passwords) and docs/routers-status.json (last regions).

GitHub Pages URL: enable Pages → source /docs → share https://<your-org>.github.io/<repo>/wifi-region-scanner.html
